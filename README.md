# 戦国将棋 ― 信長・秀吉・家康 ―

戦国の三英雄(織田信長・豊臣秀吉・徳川家康)の合戦を、将棋で追体験しながら、日本史が学べる和風の将棋アプリです。PWA なので、ホーム画面に追加してアプリのように使えます(オフラインでも動きます)。Vite + TypeScript + vite-plugin-pwa。

- 公開 URL: https://mmishina-art.github.io/simple_shogi/ (GitHub Pages)

## 遊び方 / 機能

- **チュートリアル(将棋のあそびかた)**: 全15レッスン。ルールを読むだけでなく、小さな練習盤で、実際に駒を動かしながら覚える。盤と駒のみかた → 歩・香・桂・銀・金・角・飛・玉の動き → 駒を取る → 持ち駒を打つ → 成る → 禁じ手(二歩・打ち歩詰め) → 王手と詰み → まとめ。目標のマスに点線の印が付き、まちがえるとヒントが出て盤がもどる。できたレッスンには「済」が付く。ルールのまとめも、ここから読める。
- **物語 〜戦国三英雄伝〜**: 信長編・秀吉編・家康編の3編、各8話(全24話)。実際の歴史にもとづき、対戦相手は、その合戦で戦った武将(今川義元・武田信玄・明智光秀・柴田勝家・石田三成・真田信繁など)。
  - **歴史の勉強になる作り**: 各話の前の会話で時代背景を説明し、勝ったあとに「歴史メモ」(年・場所・兵力・結果・意義、諸説あるものは「諸説あり」と明記)が出る。話の選択画面には年が並び、年表のように読める。将棋の勝敗は演出で、史実と違うところ(例: 本能寺で信長が勝つ)は、会話と歴史メモで説明する。
  - **対戦中のセリフ**: 対局中、対戦相手がその人物の実際のエピソードや逸話にそったセリフを話す(始まり / 駒を取った・取られた / 王手 / 対局が進んだとき)。しゃべり声も鳴る。
  - **だんだん強くなる**: 全24話を通して、CPU が3話ごとに1段階ずつ、1→8 に強くなる。
  - **次の編が開く**: 信長編を全部クリアすると秀吉編、秀吉編をクリアすると家康編が遊べる。各編の最後に、その人の最期や、次の時代への語りがある。
- **自由対局**: CPU 対戦(やさしい / ふつう / つよい / 達人、先手・後手・おまかせ)と、1 台で向かい合って指す「ふたりで」。
- **将棋のルールをすべて実装**: 成り(強制成りを含む)・持ち駒・二歩・打ち歩詰め・行き所のない駒の禁止・王手放置の禁止・詰み・千日手(連続王手の千日手は王手側の負け)・投了。
- 駒を選ぶと動かせるマスが示される(持ち駒も同様)。駒が元のマスからすべって動く(取られた駒はうすれて消える。端末の「視差効果を減らす」設定では動かない)。最後の手は、元のマスと動かしたマスを区別して表示。王手の表示、棋譜(▲７六歩 の形式)、待った。物語の対局では、相手のパネルに対戦相手の顔、自分のパネルにその編の主人公(信長・秀吉・家康)の顔を出す。盤は画面の左右いっぱいに広げ、相手のセリフは相手のパネルに重ねて出す。「だれの番か」は手番の目印(◀ 手番)で示し、最後の手・王手・考え中は相手のパネルの右に出す。
- 対局は自動で保存され、タイトルの「つづきから」で再開できる。
- **BGM**: 画面ごとに曲が変わる(タイトル / 話の選択・自由対局の設定 / 会話 / 不穏な会話(夜・軍議・敵の城・天守) / 対局 / 強敵との対局(第七話・第八話))。琴・尺八・太鼓風の音を Web Audio で演奏する自作曲(陽音階・都節音階)。対局が終わると止まり、勝敗の音が聞こえる。
- **しゃべり声**: 人物が話しているあいだ、文字に合わせて「ぽ・ぽ・ぽ」と鳴る。人物ごとに声の高さが違う(地の文では鳴らない)。
- 効果音は Web Audio で合成(駒を打つ音・王手・勝敗)。「せってい」で BGM と効果音(しゃべり声を含む)をそれぞれオン/オフ。対局画面の上のボタンでも切り替えられる。ブラウザの決まりで、最初の画面タップのあとに鳴り始める。
- 記録(物語の進み具合・設定)のファイルへの書き出し / 読み込み。
- 新しいバージョンがあると画面下に「更新」ボタンが出る。

### 物語の確認用モード

URL の末尾に `?debug=1` を付けて開くと、物語の3編・全24話が最初から選べます(クリア済みの印は付きません)。

### 歴史について

史実の出来事・年代にもとづいて書いていますが、会話やセリフは物語のための創作で、実際の発言とは限りません(「是非に及ばず」など、記録に残るとされることばや、「敵は本能寺にあり」など後世の創作とされることばは、歴史メモで区別して説明しています)。人数・日数など諸説あるものは、文中に「諸説あり」と書いています。年は、旧暦の日付も西暦の年で示しています。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
npm run icons        # アイコンの再生成(色・形は scripts/make-icons.mjs)
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/shogi.ts` | 将棋のルール(駒の動き・合法手・王手・二歩・打ち歩詰め)。DOM に触れない |
| `src/game.ts` | 対局の記録(指し手・棋譜の文字・詰み / 千日手の判定・保存形式) |
| `src/ai.ts` | CPU(駒の価値と形の評価 + α-β 法、持ち時間つきの反復深化。強さ 8 段階) |
| `src/story.ts` / `src/story-types.ts` / `src/story-data/` | 物語のデータ(登場人物、3編 24話の会話・歴史メモ、対局中のセリフ、強さ)。信長編 / 秀吉編 / 家康編と、セリフ(`talk.ts`)は別ファイル |
| `src/tutorial.ts` / `src/tutorial-view.ts` | チュートリアルのレッスン(盤の配置・目標・説明・判定)と、練習盤の画面 |
| `src/talk.ts` | 対局中の、対戦相手のセリフを選ぶ(王手・駒の取り合い・対局の進み具合) |
| `src/play.ts` | 対局画面(盤・持ち駒・選択と移動・CPU の手番・待った・投了・棋譜) |
| `src/scene.ts` / `src/portrait.ts` | 会話シーンと、登場人物の絵(SVG を自作。太い墨の線・筆のゆがみ・家紋・小道具で、22人を描き分け) |
| `src/pieces.ts` | 駒の見た目(五角形の駒に漢字) |
| `src/main.ts` | 画面の切り替え、タイトル・物語・自由対局・せってい |
| `src/music-data.ts` / `src/music.ts` | BGM の楽譜(6 曲)としゃべり声の高さ / 演奏(琴・尺八・太鼓風の音を合成、曲の切り替え) |
| `src/sound.ts` / `src/storage.ts` / `src/backup.ts` | 効果音としゃべり声、保存、バックアップ |
| `src/pwa.ts` / `src/install.ts` / `public/boot.js` | 更新ボタン、インストール方法の説明、起動失敗時の復旧 |
| `src/style.css` | 見た目(暗い固定の和風配色。色は `:root` の変数に集約) |
| `tests/` | 単体テスト(ルール・perft・CPU・対局記録・物語データ・バックアップ) |
| `e2e/` | 画面テスト(Playwright) |

## 素材とライセンス

画像(タイトルの絵・登場人物の絵・アイコンの背景)はこのリポジトリのコードで描いた自作で、効果音・BGM・しゃべり声は Web Audio で合成しています(曲もこのアプリのために作りました)。物語の文章・歴史メモ・セリフも、このアプリのために書き下ろしたものです。外部の画像・音声は使っていません(画面の文字は端末の標準の明朝体 / ゴシック体を使います)。アプリのアイコンの文字「将棋」「戦国」だけは、[Noto Serif JP](https://fonts.google.com/noto/specimen/Noto+Serif+JP) Bold(SIL Open Font License 1.1)の字の輪郭を `scripts/icon-glyphs.mjs` に取り込んで描いています(アプリの実行時には読み込みません)。
